# OpenRail Technical Committee Summary Report 2026 Q4

The fourth quarter of 2026 focused on **project applications and onboarding, infrastructure services for projects, and event and community preparations** for the OpenRail Technical Committee.

The main topic during the quarter was the "GTFS.zone Editor" application. We had multiple rounds of review for the proposal; we had a dedicated presentation and discussion with the maintainer. The TC supported the proposal and brought it to the Board. The project was accepted, and a presentation is planned for the next board meeting.

We also moved forward with the onboarding of "OSCAL4Rail". The code was migrated to the OpenRail GitHub organization.

**Infrastructure services for projects** emerged as a new theme, driven by OSRD. An OSRD demo is already running on the OpenRail infrastructure, and additional requests were raised: hosting an OSRD instance for students with authentication. Cost estimates for the demo setup were requested, with a decision to follow in a subsequent meeting.

On **security and compliance**, the TC discussed the open-source program of Aisle, a company performing LLM-based static security checks free of charge for sufficiently large open-source projects. This kind of tool was used by neither OSRD nor Netzgrafik-Editor, an application for the OSRD repository was submitted and accepted. It is a good thing that one of the projects of the OpenRailAssociation is considered large enough to access this type of service for free. A few security issues were reported and dealt with promptly by the project team. Using this type of tool more often to evaluate/ensure security still has to be discussed.

About **community events**, the FOSDEM developer room was accepted for 2027. Talk proposals were discussed and encouraged.

Finally, the committee moved **meeting invitations from Microsoft Teams to Nextcloud**.
